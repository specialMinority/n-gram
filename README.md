# C Character 1-Gram Counter

이 저장소는 C 언어로 구현한 **문자 기준 1-gram 빈도 분석 프로그램**입니다.

현재 기준 구현 파일은 다음 하나입니다.

```text
char_ngram1.c
```

기존 단어 기준 구현 파일 `ngram1.c`는 제거했습니다.

## 1-Gram이란?

1-gram은 입력을 한 단위씩 나누어 세는 방식입니다.

이 저장소에서는 단위를 **단어**가 아니라 **문자 1개**로 잡습니다.

예를 들어 입력이 다음과 같다면:

```text
aab c
```

문자 기준 1-gram은 다음처럼 셉니다.

```text
a      2번
b      1번
space  1번
c      1번
\n     1번
```

## 구현 방식

`char_ngram1.c`는 초보자가 코드를 따라가기 쉽도록 복잡한 자료구조를 쓰지 않습니다.

사용하지 않는 것:

- 구조체
- 해시 테이블
- 연결 리스트
- `qsort`

대신 핵심은 이 배열 하나입니다.

```c
size_t counts[256] = {0};
```

C에서 `unsigned char` 값은 0부터 255까지 가능합니다.
따라서 `counts` 배열을 256칸 만들면, 각 문자/바이트 값이 몇 번 나왔는지 바로 저장할 수 있습니다.

예를 들어 ASCII에서 `'a'`는 97입니다.

```c
counts['a']++;
```

는 실제로 다음과 비슷하게 동작합니다.

```c
counts[97]++;
```

## 프로그램 흐름

프로그램은 다음 순서로 동작합니다.

1. 실행 인자로 입력 파일 경로를 받습니다.
2. `fopen`으로 파일을 엽니다.
3. `fgetc`로 파일을 한 바이트씩 읽습니다.
4. 읽은 값을 `unsigned char`로 바꿉니다.
5. `counts[byte]++`로 해당 문자/바이트의 등장 횟수를 증가시킵니다.
6. 한 번 이상 등장한 문자/바이트 번호만 `order` 배열에 모읍니다.
7. `order` 배열을 빈도 내림차순으로 직접 정렬합니다.
8. 결과를 표 형태로 출력합니다.

## 출력 기준

정렬 기준은 다음과 같습니다.

1. 등장 횟수가 많은 문자 먼저 출력합니다.
2. 등장 횟수가 같으면 문자/바이트 번호가 작은 값을 먼저 출력합니다.

공백처럼 화면에 잘 보이지 않는 문자는 이름으로 출력합니다.

```text
space
\n
\r
\t
```

일반 출력 가능한 문자는 작은따옴표로 감싸서 출력합니다.

```text
'a'
'b'
'1'
```

그 외 보이지 않는 바이트는 16진수로 출력합니다.

```text
0x00
0x1B
```

## 빌드

GCC 또는 Clang:

```sh
gcc -std=c11 -Wall -Wextra -O2 -o char_ngram1 char_ngram1.c
```

MSVC:

```bat
cl /std:c11 /W4 /utf-8 char_ngram1.c
```

`/utf-8` 옵션은 소스 코드 안의 한글 주석을 안정적으로 읽기 위한 옵션입니다.

## 실행

Linux 또는 macOS:

```sh
./char_ngram1 input.txt
```

Windows PowerShell:

```powershell
.\char_ngram1.exe .\input.txt
```

## 예시

입력 파일 내용:

```text
aab c
```

출력:

```text
CHAR              COUNT
----              -----
'a'                   2
\n                    1
space                 1
'b'                   1
'c'                   1
```

## UTF-8 한글 처리 제한

이 구현은 C의 1바이트 문자 기준으로 동작합니다.

따라서 영어, 숫자, 기본 ASCII 기호는 사람이 기대하는 문자 단위로 잘 셉니다.

하지만 한글 같은 UTF-8 문자는 한 글자가 여러 바이트로 저장됩니다.
예를 들어 `가`는 화면에서는 한 글자지만, UTF-8 내부에서는 여러 바이트입니다.

따라서 이 프로그램은 한글 한 글자를 하나의 문자로 세지 않고, 내부 바이트값 여러 개로 셉니다.

한글을 진짜 문자 단위로 세려면 UTF-8 디코딩 로직을 추가해야 합니다.

## 오류 처리

- 입력 파일 인자가 없으면 사용법을 출력하고 실패 상태로 종료합니다.
- 입력 파일을 열 수 없으면 오류 메시지를 출력하고 실패 상태로 종료합니다.
- 파일 읽기 중 오류가 발생하면 오류 메시지를 출력하고 실패 상태로 종료합니다.
- 빈 파일은 헤더만 출력합니다.
